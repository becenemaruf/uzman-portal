# E-posta şablonları (Supabase → Authentication → Emails → Templates)

Her şablonun **Subject** ve **Message body (HTML)** alanına aşağıdaki değerler yapıştırılır.

- `1-kayit-dogrulama.html` — Konu: **Klinik Psikologlar — E-posta adresinizi doğrulayın**
- `2-sifre-yenileme.html` — Konu: **Klinik Psikologlar — Şifre yenileme bağlantınız**
- `3-eposta-degisikligi.html` — Konu: **Klinik Psikologlar — E-posta değişikliğini onaylayın**
- `4-giris-baglantisi.html` — Konu: **Klinik Psikologlar — Giriş bağlantınız**
